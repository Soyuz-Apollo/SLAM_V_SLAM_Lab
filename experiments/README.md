# Эксперименты

Эксперимент одной статьи хранится в её `experiments/`. Сравнение нескольких алгоритмов хранится здесь.

Папка запуска: `YYYY-MM-DD_algorithm_dataset_sequence_run01/`.

Для каждого запуска сохраняй:

- точную версию кода и локальные изменения;
- последовательность, контрольную сумму данных и диапазон времени;
- калибровку, модель камеры и преобразования между сенсорами;
- конфигурацию и команду запуска;
- версию ОС, зависимости, процессор и параметры контейнера;
- метод сопоставления временных меток и выравнивания траекторий;
- метрики с единицами измерения, длительность обработки и потери отслеживания;
- выводы, ограничения и ошибки запуска.

Шаблоны: [описание](../templates/Experiment_Template.md), [машиночитаемый паспорт](../templates/Experiment_Manifest.json).

Маленькие CSV с метриками и графики можно хранить в Git. Большие траектории, логи и реконструкции сохраняй в `data/` и указывай их пути. Траекторию лидарного SLAM обозначай как опорную оценку с собственной погрешностью, пока независимая точность не подтверждена.

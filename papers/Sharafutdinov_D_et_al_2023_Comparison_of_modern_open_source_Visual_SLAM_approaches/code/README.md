# Код для сравнительного исследования

Исходники алгоритмов из этой статьи ещё не добавлены.

Для каждого выбранного алгоритма создай отдельную папку реализации, закрепи ссылку на upstream, полный commit и лицензию. Сохрани конфигурацию для конкретного датасета и инструкцию сборки. Общие наборы данных находятся вне кода, в `data/`.

Работоспособность и результаты каждой реализации отмечаются только после проверенного запуска. Правила добавления исходников и контейнеров описаны в [[docs/WORKFLOW]].

# Эксперименты сравнительного исследования

После переноса результаты не воспроизводились. Для начала выбери один алгоритм и одну последовательность из [[Datasets_Index]], закрепи код и параметры камеры, затем сохрани траекторию и посчитай метрики по [[slam_metrics_explained_ru]].

Описывай не только ошибку на успешно пройденной части, но и долю обработанного маршрута, потери отслеживания и длительность работы. Не смешивай результаты с разным выравниванием траекторий без явного пояснения.

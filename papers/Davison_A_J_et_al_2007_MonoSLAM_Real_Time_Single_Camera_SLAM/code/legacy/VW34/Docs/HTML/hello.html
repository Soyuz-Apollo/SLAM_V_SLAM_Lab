Welcome to the documentation for the VW project

Welcome to the (sparse) documentation for the VW tool. VW is a collection of open-source (LGPL) libraries aimed to help the computer vision programmer write applications. More details can be found in the User Guide.

The documentation is split into sections as follows:

  • Home - this page.
  • User Guide - excellent help pages written by Ian describing how to install, setup and use the VW tool. Sections include
    • foreword: design aims
    • install guide
    • other excellent stuff...
  • Reference - documentation automatically created from the source code. The following indices are available:
    • a list of the classes
    • a list of the namespaces
    • an alphabetical list of all structures (classes, enumerations etc.)

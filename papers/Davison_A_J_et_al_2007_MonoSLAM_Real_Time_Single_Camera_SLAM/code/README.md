## Начать с CMake-реализации

У импортированной `github_marcromani_MonoSLAM` уже есть локальный CMake для C++14 и OpenCV 4. Из корня лаборатории:

```bash
cmake -S papers/Davison_A_J_et_al_2007_MonoSLAM_Real_Time_Single_Camera_SLAM/code/github_marcromani_MonoSLAM -B build/monoslam -DCMAKE_BUILD_TYPE=Release
cmake --build build/monoslam --parallel
```

Это команды по импортированному CMake, а не отчёт об успешной сборке. Ожидаемые цели: `monoslam` и `calibration`, исполняемые файлы в `build/monoslam/bin/`. Аргументы запуска, калибровку и ограничения сначала сверь с исходниками и заметкой [[MonoSLAM_сборка_калибровка_и_запуск]].

Исходная тестовая последовательность остаётся в прежнем проекте: `/Users/m/Desktop/SLAM_V_SLAM/monoslam_code/TestSeqMonoSLAM`. При использовании размести её в `data/monoslam/TestSeqMonoSLAM/` и передай новый путь приложению. Реальные записи в Git не добавлены.

## Контейнеры

В `containers/` пока есть только описание следующего шага. После проверенной сборки каждой реализации добавляется отдельный Dockerfile. `legacy/` с GLOW/OpenGL и ROS-реализация имеют другие зависимости, поэтому их окружение нужно проверять отдельно.

## Лицензии

Лицензия ROS-реализации сохранена в `github_rrg-polito_mono-slam/LICENSE.md`. Для `marcromani/MonoSLAM` отдельный файл лицензии при импорте не обнаружен. Для остальных исходников нужно проверить уведомления в исходных файлах и условия автора до внешнего распространения.

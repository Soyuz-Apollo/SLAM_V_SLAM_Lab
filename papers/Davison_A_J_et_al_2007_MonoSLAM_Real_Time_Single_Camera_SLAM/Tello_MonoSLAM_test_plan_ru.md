# План тестирования MonoSLAM с DJI Tello EDU

## Главная идея

Оригинальный MonoSLAM из статьи и найденная реализация в проекте работают на C++ и OpenCV. DJI Tello EDU обычно удобно подключать из Python: библиотека получает видеопоток с дрона и отдаёт кадры как изображения OpenCV.

Поэтому самый практичный путь такой:

1. Сначала собрать и запустить C++ MonoSLAM на Mac с обычной камерой.
2. Откалибровать камеру и получить файл с параметрами `Intrinsic_Matrix` и `Distortion_Coefficients`.
3. Проверить Python-поток Tello без взлёта.
4. Сохранить кадры Tello и использовать их как тестовый видеоматериал.
5. Потом связать Python-поток Tello с C++ MonoSLAM напрямую или переписать обвязку под чтение видеофайла/UDP-потока.

## Что уже сделано на Mac

- Установлены зависимости через Homebrew: `pkgconf` и `opencv@4`.
- C++ код адаптирован под OpenCV 4.
- Собраны две программы:

## Почему Tello не подключается сразу напрямую к MonoSLAM

В текущем виде MonoSLAM читает камеру так:

```cpp
VideoCapture cap(0);
```

То есть программа ожидает локальную камеру Mac. Tello же отдаёт видеопоток по Wi-Fi, и его проще получить через Python-библиотеку `djitellopy`.

На первом этапе не нужно сразу заставлять C++ управлять дроном. Достаточно получить стабильный поток кадров и сохранить его. Это позволит проверить:

- качество изображения;
- задержку видеопотока;
- наличие смаза и артефактов сжатия;
- хватает ли углов/признаков для SLAM;
- насколько часто алгоритм теряет признаки.

## Важное ограничение монокулярного SLAM на Tello

Камера Tello одна, поэтому алгоритм видит только 2D-изображение. Абсолютный масштаб сам по себе из одного видео не появляется.

Масштаб можно задать несколькими способами:

- через шахматный шаблон известного размера при инициализации;
- через ArUco/AprilTag-маркеры известного размера;
- через известную высоту полёта;
- через дополнительные датчики;
- через внешний ground truth, например motion capture.

Для первого эксперимента лучше использовать шахматный шаблон, потому что текущая реализация MonoSLAM уже инициализируется через `findChessboardCorners` и `solvePnP`.

## Запуск теста видеопотока Tello

Подключиться к Wi-Fi сети Tello, затем:

```bash
cd data/monoslam/tello_test
/opt/homebrew/bin/python3 -m venv .venv --system-site-packages
source .venv/bin/activate
python -m pip install -r requirements.txt
python tello_stream_capture.py --save-dir frames --save-every 10
```

Скрипт не взлетает и не двигает дрон. Он только включает видеопоток, показывает кадры и сохраняет каждый десятый кадр в `frames`.

Остановить можно клавишей `q`, `Esc` или `Ctrl+C`.

## Следующий технический шаг

Сейчас C++ MonoSLAM умеет читать только `VideoCapture cap(0)`. Чтобы использовать Tello, есть два варианта:

1. Быстрый вариант: добавить в C++ программу параметр `--video`, чтобы она читала видеофайл или поток вместо камеры Mac.
2. Более гибкий вариант: вынести MonoSLAM-ядро в библиотеку и передавать кадры из Python в C++ через binding или IPC.

Для дипломного прототипа проще начать с первого варианта: Python сохраняет видео/кадры, C++ MonoSLAM читает этот материал как обычный источник изображения.

## Создать удалённый репозиторий

Из корня лаборатории после восстановления авторизации:

```bash
gh auth login --hostname github.com --web --git-protocol https
gh auth status
git add .
git diff --cached --quiet || git commit -m "Initialize SLAM research lab"
gh repo create SLAM_V_SLAM_Lab --private --source=. --remote=origin --push
```

Эта последовательность предназначена для нового удалённого репозитория. Перед `git add` проверь `git status --short`, состав файлов и условия распространения сторонних материалов. Приватность здесь выбрана как исходный вариант; она не заменяет проверку условий использования.

Если удалённый репозиторий уже создан, подключи его существующий адрес командой `git remote add origin <repository_url>` и отправь ветку `git push -u origin main` после первого commit. Угловые скобки обозначают значение, которое нужно заменить.

Не сохраняй токены или приватные ключи в репозитории, заметках и сообщениях чата.

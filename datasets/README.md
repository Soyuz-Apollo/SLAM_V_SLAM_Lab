# Датасеты

Список описаний и инструкций: [[Datasets_Index]].

На GitHub открой [каталог](Datasets_Index.md).

Карточки датасетов хранятся здесь в одном экземпляре. В статье перечисляй используемые датасеты ссылками на карточки; фактические записи скачивай в `data/<dataset_id>/`.

Каждая карточка должна включать официальный сайт, условия использования, сенсоры, формат времени и калибровок, наличие и происхождение эталонной траектории, порядок скачивания и поддерживаемые последовательности. Для проверенных архивов добавляй размер, SHA-256 и дату получения.

Импортированные инструкции перенесены без повторной проверки внешних сайтов. Перед экспериментом проверь, что нужная последовательность и ссылка доступны.
